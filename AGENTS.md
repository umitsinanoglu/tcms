## 🔑 Key Conventions & Rules

1. **Port Allocations**:
   - Backend API: `http://localhost:3001` (NestJS REST API under `/api` or root routes).
   - Frontend Web App: `http://localhost:3000` (Next.js client-side SPA).
2. **Prisma Operations**:
   - Schema updates must be done in `backend/prisma/schema.prisma`.
   - Run `npx prisma db push` or `npx prisma migrate dev` in `backend/` to apply changes.
3. **Adding Features / Modifying Components**:
   - Always verify TypeScript signatures in `frontend/src/services/api.ts` before updating API endpoints.
   - When modifying frontend components, ensure compatibility with `ThemeContext`.
4. **Changelog Maintenance**:
   - When introducing user-visible features or bug fixes, record entries in `CHANGELOG.md` using `npm run changelog` or `python3 scripts/update_changelog.py`.
